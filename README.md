# Caren Car Wash - Landing Page React

Landing page premium com foco em alta conversão para lavagem detalhada de veículos.

## 🚀 Tecnologias

- React 18
- Tailwind CSS
- Material Symbols Icons

## 📋 Requisitos

- Node.js 14+
- npm ou yarn

## 🛠️ Instalação

```bash
npm install
```

## ▶️ Executar em Desenvolvimento

```bash
npm start
```

A aplicação abrirá em [http://localhost:3000](http://localhost:3000)

## 🏗️ Build para Produção

```bash
npm run build
```

## 📁 Estrutura

```
src/
├── components/
│   ├── Header.js           # Navegação fixa
│   ├── Hero.js             # Seção hero com urgency
│   ├── SocialProof.js      # Estatísticas e provas sociais
│   ├── Services.js         # Cards de serviços
│   ├── CtaSection.js       # Call to action intermediário
│   ├── Location.js         # Mapa e horários
│   ├── Footer.js           # Rodapé
│   └── FloatingButton.js   # Botão flutuante + nav mobile
├── App.js                  # Componente principal
└── index.js                # Entrada da aplicação
```

## 📱 Componentes Principais

### Header
Navegação fixa com links para seções e CTA de agendamento

### Hero
Hero section com imagem de background, urgency badges e CTAs principais

### SocialProof
4 cards mostrando estatísticas: avaliação, clientes, tempo de resposta, garantia

### Services
3 cards de serviços com imagens, features e CTAs individuais

### CtaSection
Seção intermediária com call to action e oferta de desconto

### Location
Mapa integrado com Google Maps + horário de funcionamento

### FloatingButton
Botão WhatsApp flutuante + navegação mobile bottom
